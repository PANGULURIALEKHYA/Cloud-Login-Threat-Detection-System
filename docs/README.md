# Documentation

This folder contains the technical documentation for the **Cloud Login Threat Detection System** project.

## Included Document

- **Cloud_Login_Threat_Detection_SOC_Incident_Report.pdf** – A comprehensive technical report describing the project objectives, Azure environment, Microsoft Sentinel configuration, KQL detection logic, incident investigation process, findings, and recommendations.

## Purpose

The documentation provides a detailed overview of:

- Project objectives
- Azure Resource Manager and Log Analytics Workspace setup
- Microsoft Sentinel configuration
- Kusto Query Language (KQL) query development
- Microsoft Entra ID failed login detection
- Microsoft Defender incident investigation
- Security findings and recommendations
- Project conclusion

This report serves as the primary technical documentation for the Cloud Login Threat Detection System project and provides supporting evidence of the implementation, detection workflow, and incident investigation process.
